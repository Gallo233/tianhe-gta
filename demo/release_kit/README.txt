广州 · 天河 demo（试玩版）
================================

近未来珠江新城 ·《准时达》三主角：阿杰（外卖骑手）、琪琪、强叔。
地图数据 © OpenStreetMap 贡献者（ODbL）。店名是虚构的，地名是真实的。


一、怎么打开
------------
先把整个压缩包解压（不要在压缩包里直接双击）。

【Windows 10 / 11】
  双击 start-windows.bat
  → 会弹出一个黑色窗口，浏览器自动打开游戏。玩的时候别关黑色窗口。
  · 如果提示“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
  · 如果杀毒软件（360、火绒等）拦截：选择允许 / 信任。脚本只是在本机开一个网页服务器，
    只有你自己的电脑能访问（127.0.0.1），不联网、不改任何设置。

【Mac】
  双击 start-mac.command
  → 会弹出终端窗口，浏览器自动打开游戏。玩的时候别关终端窗口。
  · 如果提示“无法打开，因为无法验证开发者”：
    打开“系统设置 → 隐私与安全性”，在下面找到 start-mac.command，点“仍要打开”。
  · 还是打不开的话：打开“终端”，输入 bash 和一个空格，把 start-mac.command 拖进终端窗口，回车。

【都不行的时候】
  电脑装了 Python 的话：在 game 文件夹里打开命令行，运行
      python -m http.server 4299
  然后用浏览器打开 http://127.0.0.1:4299/
  注意：不能直接双击 game 里的 index.html，浏览器会拦截模型加载，画面会是空的。


二、电脑和浏览器
----------------
  · 用电脑版 Chrome 或 Edge（Safari 没专门测过，出问题就换 Chrome）。手机玩不了。
  · 需要独立显卡，或者 M 系列芯片的 Mac。核显笔记本可能会卡。
  · 第一次加载要十几秒（全部在本机，不需要网络）。
  · 有声音，建议开音量。


三、操作
--------
  WASD 移动 · Shift 冲刺 · 空格 跳 · 鼠标 转镜头 · 滚轮 拉远拉近
  E    说话 · 取餐 · 交餐 · 按门禁 · 刷卡进地铁（对话里按 E 继续，1 2 3 选回答）
  F    上车 / 下车（阿杰的电动车就停在他身边；路边的车、车流里的车都能开）
  骑电动车：W 加速 · S 刹车（停住再按是倒退）· A/D 压弯 · 空格 后刹甩尾 · Q 喇叭
  开车：W/S 油门刹车 · A/D 转向 · 空格 手刹
  APM 线可以从出入口走下去，进站坐车
  1 2 3 / Tab 切换主角 · [ ] 时间快进倒退（有昼夜）· R 下雨 · H 说明 · F3 性能面板


四、送外卖（主线：第一章《五星好评》）
----------
  平台 AI“小准”自动派单，从接单那一刻开始计时（时限按电动车的速度算，走路基本送不到）。
  · 取餐：骑到黄色光柱，下车走到店门口按 E 跟店员说话。有的店出餐慢（可以催），
    有的店很“会做生意”（预制菜说成现炒、拿错单、求好评……）。
  · 送餐：骑到绿色光柱，看清订单备注——
      公交站 / 地铁口：按备注描述在人群里找到顾客，当面交（找错人有惊喜）；
      写字楼：先过保安那关，放外卖柜、打电话叫顾客下来，或者求保安放你上楼；
      住宅 / 城中村：按门禁或敲门，放门口拍照，照片里要有外卖和门牌，不然顾客说“没收到”你就要赔钱。
  · 摔车、飞坡会洒餐；送完一会儿顾客会给评价，评分太低会被“优化”。
  · 提前送到，小准会把你以后的时限压得更短一点。
  · 进度会自动保存在浏览器里。
  · 记得开声音：街坊（阿杰、麦姐、发哥、保安李伯、店员……）讲粤语，平台 AI 小准和写字楼的人讲普通话，
    字幕都是中文。地铁 APM 报站是普通话、粤语、英语三语。
  · 外卖站（出生点旁边的青绿色集装箱）可以走进去：门口饮水机接水回体力，沙发可以休息
    （订单时间照走），充电架给手机充电（小准会扣一块钱）。
  · 有些店找不到门面，在路边摆了三轮车档口，一样去档口取餐。


五、已知情况
------------
  · 这是开发中的版本：人物绑定和动作还在精修，有些模型还比较粗。
  · 路人和警察用的是内置规则 AI（开发机上的 Jev 模型决策服务没有打包进来），右上角会显示“JEV 离线”。
  · 遇到 bug 或者卡顿，截图告诉我：什么电脑、什么浏览器、在哪里、做了什么。
