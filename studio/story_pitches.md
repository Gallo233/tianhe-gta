# 故事梗概 · 三选一（GTA 式黑色幽默，近未来广州）

2026-09-28。三个方向都能直接用上已有的玩法（开车、警察追逐、外卖接单）。品牌和公司全部是虚构戏仿，真实地名和地标保留原名。
你选一个，或者说"A 的人物 + C 的主线"这样混搭都行。定下来以后我写三位主角的 Tripo 设定和第一章任务。

---

## A ·《准时达》——外卖平台算法讽刺

**一句话**：全城最高分的外卖骑手，接到了算法派来的"特殊订单"，从此被平台、警察和黑帮三方追着送货。

- **世界**：2033 年的天河。外卖平台"准时达"的调度 AI **"小准"** 给每个人打分：骑手、商家，甚至顾客。分数低于 4.8 就被"优化"。小准开始派一些不能拒绝的订单：箱子不许打开，路线不许偏离，超时就扣全家的信用分。
- **三位主角**
  - **阿杰（陈俊杰），24**：土生土长的冼村仔，4.99 分骑手，全城闯红灯最稳的人。**外卖玩法的主角。**
  - **琪琪（黎琪琪），28**：美食主播。她的"网红餐厅"其实是城中村里的幽灵厨房，全部菜品是预制菜。**负责直播和社交，被追会涨人气。**
  - **强叔（何志强），53**：猎德村拆迁后分到三栋楼的包租公，兼职"搞掂"一切，开一辆老款电动 MPV。**负责开车和帮人收尾。**
- **讽刺对象**：算法打分、零工经济、预制菜网红、"优化"文化。
- **第一章任务（对应现有系统）**
  1. 《超时》：限时 6 分钟，把一单从花城广场送到猎德大桥南（外卖接单 + 路网限时）。
  2. 《差评》：给你差评的顾客住在珠江新城 40 楼，去"沟通"一下（到达 + 对话）。
  3. 《特殊订单》：箱子不能碰，警察在查，甩掉 2 星通缉再送达（警察追逐）。
  4. 《直播事故》：琪琪直播时把阿杰拍进了镜头，全网在找这个骑手（切换主角）。
  5. 《包租公》：强叔开车，把"箱子"运过珠江，桥上有路障（驾驶 + 过桥）。
- **为什么适合**：外卖骑手本身就是穿行全城的理由，外卖接单玩法直接变成主线。

## B ·《流量城》——网红经济讽刺

**一句话**：三个过气网红为了一场"百亿流量挑战"在天河搞事，警察追得越凶，直播间人越多。

- **世界**：直播平台"赞赞"办了"天河百亿流量挑战"：谁能在广州塔、双塔、珠江上完成最出格的直播，谁就拿走平台的签约合同。全城都是飞着拍的无人机和举着手机的围观群众。
- **三位主角**
  - **琪琪，28**：前美食主播，掉粉掉到只剩 3 万，决定豁出去。
  - **Kenny 黄，31**：说唱歌手，写了一首《珠江新城》，唯一的爆款是被人拿去做鬼畜。
  - **阿妹（梁小妹），19**：技术宅，会黑进无人机和城市大屏，有点想红又不敢露脸。
- **讽刺对象**：流量至上、平台签约、网络暴力、"整活"文化。
- **玩法钩子**：**通缉星 = 直播热度**，被追得越狠，观看人数越多，有额外奖励；城市大屏可以被黑来播自己的直播。
- **第一章任务**：飙车穿过花城广场并全程直播；黑掉西塔的媒体幕墙；在猎德大桥上躲警察直到热度破百万；等等。
- **为什么适合**：近未来的媒体幕墙、全息广告、无人机都能变成玩法，不只是布景。

## C ·《云上天河》——科技公司讽刺

**一句话**：一家科技巨头把整座城市的红绿灯改成了订阅制，三个被系统"清理"掉的人决定去东塔顶上偷主密钥。

- **世界**：巨头"盘古智能"总部在东塔，它的城市大脑 **"天枢"** 接管了交通：付费会员一路绿灯，不付费的车排队到天亮。城中村被系统标为"低效区块"，准备整片清掉。
- **三位主角**
  - **阿Ray（郭睿），35**：被"毕业"的盘古算法工程师，天枢的红绿灯模块就是他写的。
  - **兰姐（冯秀兰），48**：猎德村大排档老板娘，嗓门大，全村的消息都从她这里过。
  - **小马（马骁），26**：无人驾驶出租车的"安全员"，每天坐在不需要他的驾驶座上。
- **讽刺对象**：科技巨头、订阅制一切、35 岁危机、"降本增效"。
- **玩法钩子**：天枢控制的红绿灯可以被黑（和路网信号系统直接挂钩）；无人驾驶车队可以被劫持。
- **第一章任务**：阿Ray 黑掉一个路口让兰姐的送货车一路绿灯；小马"劫持"自己开的无人车；三人在东塔下集合踩点。

## 我的建议

**A《准时达》**。它和"先能玩"的顺序最搭：外卖接单玩法现成，主角就是骑手，第一章几乎全用已有系统就能做出来，不用先等新功能。
B 的"通缉 = 流量"很好玩，可以当成 A 里琪琪那条支线的机制。
C 的"黑红绿灯"和我们的路网信号系统天然契合，可以留作第二章以后的大事件。
