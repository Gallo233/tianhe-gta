# 广州·天河《准时达》· 三名主角设定（Tripo 生成用）

2026-09-29。用户选定故事 A《准时达》（见 `story_pitches.md`）。三人做成主角切换（沿用海滨城的切人玩法），替换现在占位的 Mateo / 林汐 / Otis。
车辆和硬表面道具由我在 Blender 里建；**人物这类不规则面多的交给 Tripo**。

三人的轮廓、身高、主色互相拉开，第三人称远景也一眼能分清：
阿杰 = 细高 + 荧光青柠绿头盔；琪琪 = 娇小 + 粉紫；强叔 = 矮壮大肚 + 白背心。

## 平台"准时达"的配色（阿杰的制服和外卖车都用它）
**荧光青柠绿 `#C6F03C` + 炭黑 `#1B1D1F`**，反光条银灰。刻意避开真实平台的黄色和蓝色。
平台 logo、骑手编号这些文字我在引擎里加，**Tripo 里不要有任何文字和标志**。

## 通用规则（沿用海滨城，针对 Tripo 自动绑定的弱点）
- **贴身衣物**：不要长外套下摆、披风、围裙、宽大裤腿。Tripo 不给布料加骨骼，大块垂坠布料一抬腿就翻起来。
- **平底鞋**。
- **头发贴头**：短发、齐下巴的短发或头盔，不要披肩长发和马尾（没有头发骨，会插进肩膀）。
- **手里什么都不拿**，身上没有会晃的挂件（包带、吊坠、钥匙串、工牌挂绳）。手机、保温杯、外卖箱这些我在引擎里挂到手骨上。
- 写实偏风格化的游戏角色，干净的 PBR 贴图。

Character turnaround reference sheet for a 3D game model: front view, left side view and back view of the same character side by side, full body from head to toe, strict T-pose with arms straight out horizontally and fingers spread, feet shoulder-width apart and flat on the ground, neutral expression, even flat studio lighting, no cast shadows, plain light grey background, no text, no logos.

## 交付规格（和海滨城完全一样）
1. **生成**：全身 T-pose，开纹理 + PBR（高清纹理），**不开"分件 / parts"**；三角面约 2 万（上限 3 万）。先看预览：头到脚完整、双臂水平、双腿分开，不对就重出。
2. **绑定**：人形（biped），**Tripo 规范**；能选就选 `Hip / Pelvis / Spine01 / L_Thigh …` 这套解剖骨架（v1.0）。绑完看左右手臂和腿骨数一致、手指齐全。
3. **动作**，每个动作单独出、单独导出：
   - 必须：**idle 待机、walk 走、run 跑、jump 跳**
   - 有就加：sprint 冲刺、turn 转身、fall 下落
   - 阿杰多要一个：**骑车坐姿**（动作库里有 sit / ride 类就出一个；没有的话我用程序把 idle 摆成骑姿）
   - 琪琪有就加：**举手机自拍 / 挥手**（直播任务用，没有也行）
   - **不要勾"原地 / in place"**。原地化我在程序里做。
4. **导出**：带动画的一律 **FBX**；另导一份不带动画的 T-pose 模型（FBX / GLB 都行），贴图打包或附 PNG。
5. **放这里**，文件名随意：
   - `guangzhou/incoming/ajie/`
   - `guangzhou/incoming/qiqi/`
   - `guangzhou/incoming/qiangshu/`

## 收到后我这边做什么
1. 校验骨架（骨数、左右对称、手指链）和每条动画的通道覆盖；
2. Blender 里 FBX 转 GLB，按上表身高定尺寸，贴图压到 2K，做 LOD1；
3. 检查肩、髋、手指三处，有明显问题先截图给你看再决定修不修；
4. 接进 demo：替换占位三人，挂上道具（阿杰的手机和外卖箱、琪琪的手机支架、强叔的保温杯），配出生点。
