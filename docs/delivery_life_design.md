# 《准时达》外卖玩法 2.0 · 设计（2026-09-30）

用户试玩后的反馈：取餐点和送餐点既没有店也没有人，送达也不能“放门口拍照”；玩法要更贴近现实生活，要能从中体会到黑色幽默（无良商家、刁蛮顾客、好心人……），剧情和玩法一定要做好。

目标：每一单都是一段有人、有地方、有选择的小故事；普通单用随机事件库拼出来，剧情单串成第一章。

---

## 1. 一单的完整流程

| 阶段 | 现实里骑手做什么 | 游戏里 |
|---|---|---|
| 派单 | 手机响，抢单或被系统强派 | 手机弹出订单卡：商家、送达点、距离、配送费、**小准限时**、**顾客备注**。「小准已为您自动接单」 |
| 到店 | 找店、停车、到取餐窗口报单号 | **店面**（招牌、取餐窗口、外卖架、店员、等餐的同行）。走到窗口按 E，和店员对话 |
| 等餐 | 出餐慢就干等，时间照样算骑手的 | 商家事件：正常 / 出餐慢（可以催单）/ 无良（预制菜、好评返现、拿错单、提前点「已出餐」）/ 好心（送水、打包加固） |
| 送餐 | 路上被催、被改地址、被加要求 | 已有的骑行 + 餐品完好度；手机收到顾客消息 |
| 送达 | 按地方不同：当面交、放门口拍照、保安拦、外卖柜 | 见下表 |
| 评价 | 送完才是开始 | 20–60 s 后手机收到评价：星级 + 顾客原话 + 小准点评；「未收到」可以用照片申诉 |

送达方式（按地点类型）：

| 地点 | 方式 |
|---|---|
| 公交站、地铁口 | 顾客在等，按备注里的描述**找人当面交**（找错人有台词） |
| 写字楼 | **保安拦外卖**：放外卖柜 / 打电话叫顾客下楼（等）/ 送上楼（黑屏等电梯，时间流逝） |
| 住宅楼、城中村 | **放门口拍照**：放下外卖，手机取景，把外卖和门牌都拍进去才算有效证据 |
| 酒店 | **送餐机器人**来接，机器人的评分比你高 |
| 快递柜 | 放进柜子 |

## 2. 反复出现的人物

- **麦姐**：「麦姐煲仔饭」老板娘，好心人。出餐慢但会塞给你一瓶水，下雨天多套一层袋子。
- **发哥**：「赛博炸鸡」老板，无良商家。当着你的面把预制菜放进微波炉说是现炸；搞好评返现；自己出餐慢还骂骑手。
- **王总**：写字楼 40 楼的顾客，刁蛮。不接电话、不肯下楼、准时也给差评。第一章结尾揭晓他是小准的产品经理。
- **李伯**：写字楼保安，好心人。儿子也送外卖，偶尔放你走员工电梯。
- **糖水阿婆**：街边请你喝绿豆沙。
- **刘小姐**：网红顾客，刁蛮。点一杯冰美式要你送到拍摄现场，冰化了给差评，还要你帮她拍照。
- **阿伟**：竞品平台「快到家」的骑手，嘴毒心善，会告诉你哪家店出餐慢。
- **小准**：平台 AI，全程旁白，永远礼貌，永远在压榨。

## 3. 第一章《五星好评》（剧情单，穿插在普通单之间）

1. **《第一单》**（教学）：麦姐煲仔饭 → 公交站当面交。教：订单卡、取餐窗口、找人交餐、评价。
2. **《现炸》**：赛博炸鸡的发哥当着你的面用微波炉加热预制鸡块，还叫你「帮忙说系现炸嘅」。送到写字楼，保安拦住，第一次遇到外卖柜。
3. **《四十楼》**：给王总送餐。保安不让进，王总不下楼、不接电话，坚持要送上 40 楼。怎么选他都不满意（黑色幽默：选项全是坑）。评价：一星「骑手态度差」。
4. **《好评返现》**：发哥给你 ¥20，让你用自己的账号给他刷五星。收不收？收了后面会被小准查出来。
5. **《家门口》**：冼村握手楼，第一次放门口拍照。顾客半小时后投诉「没收到」，照片拍得好就申诉成功，拍得不好就被扣钱。
6. **《差评》**：阿杰评分跌破 4.8，小准发出「优化预警」。去写字楼找王总「沟通」。王总说出真相：他就是给骑手定时限的人，「我每天都点外卖，就是为了测你们」。结尾：小准派来一张不能拒绝的「特殊订单」（第二章的钩子）。

## 4. 普通单的随机事件库

- **商家**：正常；出餐慢（可催单）；预制菜；好评返现；拿错单（不核对的话顾客投诉）；塞小广告；提前点「已出餐」让你背超时；送你一瓶水；打包加固（完好度扣得少）。
- **顾客**：正常道谢；好心打赏；给你一瓶水；嫌慢（其实没超时）；要你带东西（顺路去便利店，打赏更多）；不接电话；改地址；「没收到」要求退款；只点一杯可乐（配送费比餐贵）；给狗点的外卖；同行点外卖。
- **好心人**：摔车后路人来帮忙扶车；保安放行；糖水阿婆；同行告诉你哪家店慢。

## 5. 场景

参考照片来建（Commons），按荷塘的细节密度：
- **街铺套件**（贴在最近那栋楼的首层外墙上，朝向人行道）：茶餐厅/烧腊（灯箱招牌、铝框玻璃门、卷闸门箱、明档、外卖取餐架、红塑料凳、菜单灯箱、空调外机）、奶茶/咖啡/糖水（亮面门头、点单窗口、出杯台）、便利店（玻璃门面、货架、门口冰柜）、商场取餐点（智能取餐柜）。招牌字是网页里画的，用虚构店名。
- **写字楼入口**：保安、外卖柜（近未来智能柜，屏幕上写着「外卖请放柜，骑手禁止入内」）。
- **住宅单元门 / 城中村铁门**：防盗门、可视对讲、门牌号、福字和春联。
- **外卖袋**：准时达的青柠绿袋子，订单小票钉在上面。

## 6. 实现分工

- `delivery/Dialogue.ts`：对话框（说话人、打字效果、1/2/3 选项），头顶气泡。
- `delivery/Actors.ts`：店员、保安、顾客、路人等 NPC（程序化人体 + 穿着预设 + 姿势），可以对话。
- `delivery/Places.ts`：每个取送点在楼上的挂点（最近的外墙边、朝向人行道）。
- `delivery/Orders.ts`：订单状态机、事件抽取、剧情单、评价。
- `delivery/Script.ts`：全部台词和事件（数据）。
- `delivery/PhotoMode.ts`：放门口拍照。
- Blender：`scripts/gz_shopfront.py`（街铺、入口、门、外卖柜、外卖袋）。
