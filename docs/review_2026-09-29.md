# 广州·天河 demo 评审报告（对标 GTA 类开放世界）

2026-09-29 · 评审对象：`guangzhou/demo`（阶段 2 画质升级之后）· 机器：Apple M5，Chrome 内核预览窗

## 0. 结论

**画面有辨识度了，可玩的物理底座不合格。** 夜景、雨景、珠江天际线、城中村街面已经有“广州 GTA”的味道；但车辆没有重力、城市道具没有碰撞、地图没有边界，这三项是阻断级问题，任何玩家开几分钟就会碰到。另外 1440p 下 GPU 帧时间 20–25 ms，达不到 60 fps。

- **自动化回归基线：18 项里 4 项通过、14 项失败**（测试在 `src/qa/QA.ts`，运行 `__GZ__.qa.run()`，明细见第 5 节）。
- **优先级**：P0（阻断，5 项）→ P1（严重穿帮 / 性能，10 项）→ P2（和荷塘、GTA 的质量差距，按系统列出）。
- 修复顺序、接口设计、测试写法都在 `docs/TDD_next_session.md`；下一会话从 `HANDOFF.md` 顶部开始。

## 1. 评审方法

1. 在游戏里用调试钩子逐项复现（`__GZ__.teleport / shotAt / step`），截图取证；
2. 把每个问题写成可重复的自动测试（先红后绿），结果即第 5 节的基线；
3. 读相关代码找根因（`systems/Driving.ts`、`world/Collision.ts`、`world/StreetFurniture.ts`、`systems/Traffic.ts`、`render/RenderPipeline.ts`）；
4. 性能用 GPU 计时查询（`__GZ__.gpu()`）在 2048×1536 和 2560×1440 两种分辨率下测，并逐项开关模块定位瓶颈。

## 2. P0 · 阻断级

### P0-1 车辆没有重力，离地超过 1.8 m 就一直悬空
- **现象**：车放在广场上方 8 m、江面上方 13 m，2 秒后高度不变（VEH-01）。从桥面护栏缺口、匝道边缘开出去都会悬在半空继续开。见 `docs/img_float_river.jpg`。
- **根因**：`Driving.update()` 的贴地只是“从车身上方 1.2 m 往下找 3 m 内的地面，找到就插值过去”。找不到就什么也不做：没有竖直速度，也没有重力。
- **影响**：落水检测、坠落、跳跃、碰撞之后的姿态全都依赖它。

### P0-2 车能在珠江水面上开
- **现象**：车放在江面上 0.2 m 处，一直不下沉、不触发“掉进珠江”（VEH-02）。
- **根因**：同 P0-1（河床在 -7 m，超出 3 m 探测范围）。另外 `Game.waterCheck` 只在 y < -0.6 时触发，悬空的车永远不会触发。

### P0-3 地图边界敞开
- **现象**：往东开能开出地图东界 100 m 以上，下面没有地面（VEH-03）。
- **根因**：碰撞只覆盖地图范围，没有边界墙；远景地面（backdrop）不参与碰撞。

### P0-4 城市道具零碰撞
- **现象**：人和车都能穿过路灯杆（6,793 根）、行道树（10,475 棵）、护栏（57,630 段）、护柱（15,504 根）、公交站（314 座）、长椅 / 垃圾桶 / 消防栓 / 电箱 / 花箱（约 6,400 件）、信号灯杆（VEH-06/07、CHR-01/02/03 全部失败）。
- **根因**：`collision.glb` 只导出了地面、道路、楼体和地标棱柱；树和路灯是 GN 实例，家具是网页端实时摆放的，都没有进入任何碰撞结构。

### P0-5 车与车互相穿透
- **现象**：开车横撞停着的车，重叠 2.17 m（VEH-08）。撞车流的车时车头车尾会插进去。
- **根因**：停着的车只对“人”做了推开（`pushFromCar`），对玩家的车没有。和车流的碰撞用的是“玩家车中心点 + 半宽半径”对车流车包围盒（`Traffic.pushOut`），车长方向没有被考虑，车流车本身也不受力。

## 4. P2 · 质量差距（对标荷塘建模标准和 GTA 体验）

**车辆**
- 没有内饰：透过车窗看不到座椅和方向盘。
- 没有损坏：凹陷、碎玻璃、冒烟、掉保险杠都没有。
- 没有刹车灯和转向灯的逻辑：尾灯亮度恒定。
- 没有轮胎烟、刹车痕、溅水。
- 车流里没有摩托、电动车、外卖骑手。
- 公交不进站。

**世界（和荷塘的精度差距）**
- 大剧院还是多面体：真实的是双砾石 + 三角分格幕墙。省博、图书馆是示意级。
- 远景城区是均匀方盒子，航拍时和近景落差大。
- 信号灯是直杆：广州多为悬臂式，还带行人灯和倒计时。
- 缺少城市元素：路名牌、方向门架、路面导向箭头、公交专用道、停车位、井盖、共享单车、地铁站出入口（珠江新城有十几个，places 里有站名）、骑楼、城中村窄巷和头顶的电线、小贩摊。
- 楼顶是平的：广告牌、水箱、天线、直升机坪只有少量 Blender 设备盒。

**AI**
- 警察只有车，不会下车追，没有直升机、路障。
- 车流不打转向灯，不礼让救护 / 警车。
- 行人对雨没有反应：不打伞、不躲雨。
- 行人对撞车只会倒地，没有围观、拍照、逃跑的分层反应。

**渲染**
- 阴影只覆盖玩家周围 160–260 m，高速驾驶和航拍时远处楼没有投影。可以考虑级联阴影或远景烘焙 AO。
- SSR 只能反射屏幕里的东西，屏幕下沿的倒影会消失。它按高度阈值判定"地面"，所以桥面和高架湿了不反光。
- 夜景整体偏橙红，路灯只有一种色温。广州现在多是 LED 白光，老城区是钠灯。
- 下雨时车窗没有雨滴，没有雨刷，远处没有雨幕。

**音频**
- 没有引擎（转速 / 换挡）、轮胎、碰撞、环境（车流、人声、雨、江风）、电台、界面音效。

**玩法与 UI**
- 没有任务系统，阶段 3 还没开始。
- 没有手机，而"准时达"App 是剧情核心。
- 没有全屏地图、GPS 导航路线、暂停菜单、设置（画质 / 按键 / 音量）、存档。

**工程**
- 回归测试只能在浏览器里手动调用，还没有无头运行（Playwright）和 CI。
- 本机多个会话同时开页面时，GPU 计时不可信。

## 6. 性能明细（2560×1440，动态分辨率关闭）

| 场景 | GPU 中位（ms） | draw call | 三角面（含阴影，M） |
|---|---|---|---|
| 出生点街景 白天 | 20.5 | 543 | 2.80 |
| 塔楼方向 白天 | 22.9 | 598 | 2.98 |
| 出生点街景 夜 | 20.0 | 421 | 1.83 |
| 塔楼方向 夜 | 22.4 | 454 | 1.97 |
| 塔楼方向 雨夜 | 25.2 | — | — |

同一机位逐项关闭（白天塔楼方向 22.6 ms）：去掉 14 盏动态灯 → **14.2**；分辨率 75% → 15.1；隐藏树和路灯 → 20.4；隐藏立面构件 → 21.5；关 SSR / 不更新阴影 / 隐藏街道家具 / 隐藏近未来层 → 变化 < 0.2。CPU：每帧中位 0.9 ms，P95 1.8 ms，进入新街区生成立面时单帧最高 15 ms。加载（有缓存）2.6 s，JS 堆 245 MB，150 个着色器程序。
