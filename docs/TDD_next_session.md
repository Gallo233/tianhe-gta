## 1. 车辆物理 v2（P0-1、P0-2、P0-3、P1-1、P1-8）

**原则**：保留 `DriveCar` 的对外字段（`obj / half / heading / speed / steerAngle / impact / parked / wheels`），这样 `Game`、`Police` 的调用都不用改。把 `Driving.update()` 的内部换成 `systems/VehiclePhysics.ts`。平路手感以 VEH-05 为准，不许变差。

**状态新增**：`vel: Vector3`（竖直分量独立积分）、`pitch`、`roll`、`airborne`、`airTime`、`contacts[4]`、`lastSafe {pos, heading}`、`inWater`、`waterT`。

**四轮射线悬挂（街机向，稳定优先）**
- 挂点：模板里的车轮位置（`WheelSpec.pos`，车身局部坐标）。每帧从挂点上方 0.5 m 向下打射线，长度 = 0.5 + 静止行程 0.22 + 最大行程 0.25 + 轮半径。
- 至少一个轮子着地时：
  - 目标车身高度 = 着地轮接触高度的平均 + 离地高度。
  - 目标俯仰 = atan((前轮平均 − 后轮平均) / 轴距)，目标侧倾 = atan((左 − 右) / 轮距)。
  - 竖直方向做临界阻尼弹簧（频率约 3 Hz）。俯仰和侧倾按速率插值，每秒最多 60°。
- 四个都没着地：`airborne = true`，`vel.y += -22 * dt`（沿用 `PHYSICS.gravity`），保持水平动量，保留 20% 的空中转向。
- 落地：`impact = -vel.y`，大于 6 m/s 时镜头震动（以后接损坏）。
- 坠落探测另打一条长射线（从车身中心往下 200 m），用来判断下方是深坑还是虚空。**防穿地**：每帧检查车身中心和上一帧之间有没有穿过地面三角形（射线段检测），穿了就放回地面以上。

**落水**：`world/Water.ts`
- 规则：车身中心 y < -2.8 + 0.3，或下方地面低于 -5（河床）且车身低于 0.5 → 判定入水。
- 入水后：水平速度每秒衰减 80%，以 1.5 m/s 下沉；2 s 后黑屏淡出，放回 `lastSafe`，提示“掉进珠江了”。
- `lastSafe` 每 0.5 s 更新一次，条件：四轮着地、不在水里、不在桥面边缘 3 m 内。**必须落在路面上**（用 RoadNet 最近车道点校正）。

**地图边界**：`world/Bounds.ts`
- 软边界：离边界 30 m 内持续施加向内的推力，HUD 提示“前方无路”。
- 硬边界：往碰撞 BVH 加 4 面 30 m 高的薄墙（在 `Collision` 构造时追加几何）。

**需要变绿**：VEH-01、VEH-02、VEH-03、VEH-04。VEH-05 保持绿。

**新增测试（先写红）**

| 编号 | 场景与通过条件 |
|---|---|
| VEH-09 | 从桥面护栏缺口以 12 m/s 开出：3 s 内落到下方地面或水里，全程不低于地面 0.2 m |
| VEH-10 | 5 m/s 能爬上 0.15 m 路缘；遇到 0.5 m 台阶被挡住 |
| VEH-11 | 25 m/s 冲过坡顶：腾空 ≥ 0.3 s，落地后速度保留 ≥ 60%，姿态 1 s 内回正 |
| VEH-12 | 沿猎德大桥北引桥开到桥面再下桥（约 1.1 km）：腾空帧 < 0.2 s，高度误差 < 0.3 m，俯仰误差 < 3° |
| VEH-13 | 落水救回后 `lastSafe` 在车道上（离车道中心线 < 3 m），不在水面 |

## 2. 道具碰撞（P0-4）

新模块 `world/PropColliders.ts`：2D 网格哈希（格 8 m），里面存简单图元。

```ts
type Circle = { x: number; y: number; r: number; z0: number; z1: number; kind: string };        // Blender xy
type Box    = { cx: number; cy: number; hx: number; hy: number; c: number; s: number; z0: number; z1: number; kind: string };
resolveCircle(p: Vector3, r: number, y0: number, y1: number, out: Vector3): boolean;   // 人
resolveBox(center: Vector3, hx: number, hz: number, yaw: number, y0: number, y1: number, out: Vector3, normal: Vector3): boolean;  // 车（SAT）
raycast(origin: Vector3, dir: Vector3, far: number): number;                           // 镜头弹簧臂
```

**来源和形状表**（数量级约 9 万个图元）

| 来源 | 形状 |
|---|---|
| 路灯杆 `city.lampPoles` | 圆，r 0.14（tall）/ 0.10（short），z 0–11 |
| 树 `city.treePos` | 圆，榕树 0.45、木棉 0.35、大王椰 0.3（乘以实例缩放），z 0–4 |
| 信号灯杆（`SignalLamps` 的杆位） | 圆，r 0.15 |
| 护栏 | 盒，2.0 × 0.08，z 0–1.05 |
| 护柱 | 圆，r 0.07 |
| 长椅 | 盒，1.9 × 0.5，z 0–0.62 |
| 垃圾桶 | 盒，0.9 × 0.44 |
| 花箱 | 盒，2.06 × 0.86 |
| 消防栓 | 圆，r 0.13 |
| 电箱 | 盒，0.9 × 0.5，z 0–1.5 |
| 公交站 | 后墙 8 × 0.15、侧墙 0.15 × 1.4、灯箱 0.25 × 1.3（顶棚不算） |
| 树池 | 不算 |

家具来源：`StreetFurniture` 在构造时把 `places` 列表存下来并对外暴露。

**接入**
- `Controller.update`：BVH 胶囊修正之后再 `resolveCircle`。
- 车辆物理：车身 OBB 对图元做 SAT，推出去，沿法线的速度分量乘 0.25–0.75（和墙一样处理）。
- `CameraRig.occluder`：加上 `props.raycast`。
- 警车：走同一套车辆物理，自然生效。

**可破坏（P2，先不做）**：垃圾桶、路灯杆被 > 8 m/s 撞击时变成刚体碎片，从碰撞表移除，对应实例缩放为 0。

## 4. 摆放规则（P1-3、P1-4、P1-5）

`StreetFurniture` 改成**先算禁放区，再摆放**。

**禁放区**
- 过街走廊：过街线两侧各 1.5 m，两端各延伸 2 m。
- 公交站：站亭长度，沿路缘两侧各加 4 m。
- 出入口：`walkways` 里 `link` / `foot` 边或 service 道路和干道路缘的交点，留 6 m。
- 店门：`places.json` 的 `door` 离路缘 5 m 以内时，留 4 m。

**摆放规则**
- 护栏跳过所有禁放区。
- 公交站先摆，护栏后摆。
- 护柱摆在过街口两侧 ±（过街宽度 / 2 + 0.8 m），**不放在线上**。
- 人行道小件不进过街走廊和店门区，离路灯杆和树 ≥ 1.5 m。

**需要变绿**：LAY-01、LAY-02、LAY-03。

**新增测试**

| LAY-04 | 人行道小件离路灯杆、树 ≥ 1.2 m |

## 5. 性能（P1-2）

预算（2560×1440，动态分辨率关闭时）：白天 ≤ 14 ms，夜 ≤ 16 ms，雨夜 ≤ 18 ms。达到后动态分辨率只在极端场景才会介入。

1. **白天不挂动态灯（约省 9 ms）**。加载时编译两遍：灯可见时 `renderer.compile(scene, camera)` 一次，不可见时再一次，three 会把两套着色器程序都缓存下来。之后按 `night > 0.05` 切换 `nightLights.group` 和 `headlights.group` 的 `visible`，带滞回，切换时不会重编译。要验证黄昏切换时没有卡顿。
2. **夜里的路灯光照改成自定义**。去掉 three 的 12 盏 PointLight，改成 `gzLamps` uniform 数组（8 盏，vec4 位置 / 半径 + 颜色），只在地面、人物、车辆、近景立面这几类材质里算，按距离提前退出。玩家车灯的两盏 SpotLight 保留。
3. 立面着色器：`gzAA ≈ 0`（远处）时跳过室内映射分支。
4. 树：中距离考虑面片替身（从叶簇烘焙），减少近景实例的顶点提交。

**测试**

| 编号 | 场景与通过条件 |
|---|---|
| PERF-01（信息项，修完后改为严格） | 固定四个机位（出生点街景 / 塔楼方向 × 白天 / 夜），1440p GPU 中位 ≤ 预算 |
| PERF-03 | 19:00 → 19:30 时钟快进期间，没有 CPU 帧 > 25 ms |
